# Locate landing

Static one-page site for the Italian listing locator. No build step. Same design system as umbra-landing (tokens, self-hosted fonts, light default with a dark toggle), its own copy and components.

- `index.html`: the page
- `css/theme.css`: tokens and components
- `assets/fonts/`: Source Serif 4, ZT Nature, Geist Mono (woff2)
- `CNAME`: find.ater.digital

The Gravedona figures come from sonde/locate/TEST-2026-10-26.md and the regression runs in sonde/locate/app. The product mock is drawn in HTML and SVG, in the contextual.cc style of ~/umbra/app-v3. "Locate" is a working title.
