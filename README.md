# Sonde landing (v3, the check before the offer)

Static one-page site for Sonde's pre-offer check on Italian houses. No build step. Same design system as umbra-landing (tokens, self-hosted fonts, light default with a dark toggle).

- `index.html`: the page
- `css/theme.css`: tokens and components (the v2 mock styles are still in the file, unused)
- `assets/fonts/`: Source Serif 4, ZT Nature, Geist Mono (woff2)
- `CNAME`: find.ater.digital

Every example on the page comes from the Todi sample check of 13 Nov 2026 (sonde/checks/2026-11-13-todi). The form builds a prefilled email to hey@ater.digital, no backend.
