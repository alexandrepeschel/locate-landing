# Locate landing

Static one-page site for the listing-to-parcel finder. No build step. Same design system as umbra-landing (tokens, self-hosted fonts, light default with a dark toggle), its own copy and components.

- `index.html`: the page
- `css/theme.css`: tokens and components
- `assets/fonts/`: Source Serif 4, ZT Nature, Geist Mono (woff2)
- `assets/img/`: cropped app screenshots from the 30 Oct regression run
- `CNAME`: find.ater.digital

Every figure on the page comes from the two 30 Oct regression reports (sonde/locate/app/REPORT-2026-10-30.md and sources/REPORT-2026-10-30.md). "Locate" is a working title.
